Инструкция по загрузке изображений в галерею:

Вы можете загрузить свои фотографии для каждого из 6 разделов галереи прямо в эту папку.
Пожалуйста, загружайте фотографии со следующими именами (поддерживаются форматы .jpg, .png, .jpeg, .svg):

1. Учебные аудитории и мастерские:
   Имя файла: gallery1.jpg (или gallery1.png, gallery1.jpeg)

2. Студенческий совет и КВН:
   Имя файла: gallery2.jpg (или gallery2.png, gallery2.jpeg)

3. Спортивный комплекс НЭК:
   Имя файла: gallery3.jpg (или gallery3.png, gallery3.jpeg)

4. Конкурс "Профессионалы":
   Имя файла: gallery4.jpg (или gallery4.png, gallery4.jpeg)

5. Торжественная линейка 1 сентября:
   Имя файла: gallery5.jpg (или gallery5.png, gallery5.jpeg)

6. Наш учебный полигон:
   Имя файла: gallery6.jpg (или gallery6.png, gallery6.jpeg)

Параметры изображений:
- Формат: JPG, JPEG, PNG, SVG
- Рекомендуемое разрешение: 1200x800 пикселей (или любое другое с соотношением сторон 3:2 или 4:3)
- Размер: до 5-10 МБ (для быстрой загрузки приложения лучше оптимизировать до 1-2 МБ)
- Если файл не загружен, приложение автоматически покажет красивую стилизованную карточку-заглушку с соответствующей иконкой!
